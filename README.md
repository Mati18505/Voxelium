# Voxelium
**Voxel engine with client server architecture made with rust and Bevy.**

Its main goals are performance, ease of extensibility, and making creating voxel-based games easier than ever before.

## Features
* Network synchronization.
* Loading and unloading chunks: from RAM and from disk.
* Easliy extensible: for example you can add new block types or biomes by just editing json file.
* Multiple optimizations: you can choose what optimization you want.
* Optimized for multiple threads.
